Kas Mudah logo assets

Files:
- logo.svg: scalable vector logo, transparent background
- logo.png: PNG version of the logo
- favicon.svg: compact receipt-and-leaf icon for browser tabs
- favicon.png: 256x256 PNG favicon
- favicon.ico: multi-size ICO favicon

HTML usage:
<img src="./logo.svg" alt="Kas Mudah" class="logo">
<link rel="icon" href="./favicon.svg" type="image/svg+xml">
<link rel="alternate icon" href="./favicon.ico">

Keep these files in the same folder as index.html (or adjust relative paths).
